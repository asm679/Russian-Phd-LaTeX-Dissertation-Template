Итогом выполнения диссертационной работы на соискание ученой степени кандидата технических наук, выполненной с целью совершенствования методики передачи координат в широком диапазоне расстояний при использовании современных методов обработки спутниковых данных, а также исследование различных факторов, влияющих на точность определения координат по методу PPP, является разработанная методика по созданию геодезических сетей при использовании метода PPP обработки спутниковых данных.

Основные научные и практические результаты заключаются в решении следующих актуальных научно-технических задач:

\begin{enumerate}
	\item Выполнен информационно-аналитический обзор существующих методов создания геодезических сетей с использованием спутниковой аппаратуры. Приводятся основные требования по созданию геодезических сетей на примере ВГС (высокоточной геодезической сети) и СГС-1 (спутниковой геодезической сети).
	\item Выполнено теоретическое и экспериментальное обоснование возможности использования алгоритма точного позиционирования (PPP) для построения геодезических сетей в различных диапазонах расстояний. Проведенные исследования позволили сформулировать положения разработанной методики создания геодезических сетей.
	\item Разработана методика создания геодезических сетей с использованием метода PPP обработки спутниковых данных. Отличительной особенностью предложенной методики является сокращение временных затрат и повышение уровня точности. Методику можно применять при построении геодезических сетей, в том числе государственной геодезической сети. В ходе экспериментальных исследований было установлено, что определение координат с использованием метода PPP в среднем получается точнее на 30\%, чем при классической обработке в статике.
\end{enumerate}

Результаты диссертационного исследования рекомендуются к использованию при поддержании и развитии ГГС, а также для дальнейшего исследования точностных возможностей определения координат при использовании метода PPP.

Перспективы дальнейших исследований по данному направлению заключаются в проведении фундаментальных исследований по возможности использования метода PPP обработки спутниковых данных для создания Фундаментальной астрономо-геодезической сети.
