В существующих нормативных документах указано, что продолжительность измерений должна быть трое суток при создании Высокоточной геодезической сети (далее --- ВГС). При создании Спутниковой геодезической сети первого разряда (далее --- СГС) продолжительность измерений должна быть не менее $8$~часов. При создании ВГС и СГС минимальное количество используемых спутников должно быть не менее шести при величине pdop не более $20$.


С точки зрения общих требований предлагается внести следующие корректировки: продолжительность измерений для сетей СГС --- $2$~часа при количестве повторений измерений: $2$~раза. Для сетей ВГС --- $3$~часа при количестве повторных измерений: $3$~раза. В обоих случаях минимальное количество спутников должно составлять не менее $15$. Перерывы между сеансами измерений не менее $12$~часов. Данные рекомендации основываются на результатах проведенных в данной диссертационной работе исследованиях.

На основании выполненных теоретических и практических изысканий, подробно описанных в разделах~\cref*{disch:ch1,disch:ch2,disch:ch3} диссертации была разработана методика создания геодезических сетей при использовании РРР-алгоритма.

Разработанную методику можно разделить на 3 основные блока:
\begin{description}
	\item[Блок~1] --- сбор и предварительная обработка данных по РРР-алгоритму.
	\item[Блок~2] --- этап обработки спутниковых измерений.
	\item[Блок~3] --- уравнивание и предоставление данных.
\end{description}

На этом этапе построения геодезических сетей происходит сбор данных с их первичной проверкой на корректность. Для выполнения спутниковых измерений должна использоваться современная спутниковая геодезическая аппаратура. ГНСС приемники должны быть многочастотными и мультисистемными.

По результатам приведенных выше исследований, можно сделать вывод, что продолжительности измерений, не превышающей трёх часов, достаточно для достижения оптимальной точности определения координат, при соблюдении ряда условий.
При увеличении продолжительности измерений свыше трёх часов, точность практически неизменна. 
При этом обязательными условиями являются: pdop фактор должен быть менее~$3,0$, а количество спутников свыше~$15$. Также продолжительность измерений должна составлять $3$~часа с перерывами между сеансами измерений $12$~часов.

На сегодняшний день существует достаточно обширное количество способов уравнения геодезических данных. Несмотря на разнообразие различных способов уравнивания в их основе лежит метод наименьших квадратов (далее~--- МНК). Для уравнивания данных, полученных по РРР-алгоритму могут быть использованы следующие способы уравнивания: 
\begin{enumerate}
	\item Классический способ уравнивания с составлением нормальных уравнений.
	\item Параметрический способ уравнивания через поиск решения на примере поиска решения в ПО~Microsoft~Excel.
	\item Условный способ уравнивания через поиск решения на примере поиска решения в ПО~Microsoft~Excel.
\end{enumerate}

Также стоит отметить, что в некоторых ПП (например, в Bernsese) сразу реализована возможность уравнивания. При использовании как классического, так и методов нелинейного программирования, существует возможность уравнивания только в полуручном режиме, когда уравнения связи составляются исполнителем. 

Для оценки точности результатов уравнивания могут быть использованы два способа: 
\begin{enumerate}
	\item по невязкам в замкнутых фигурах;
	\item по разности двойных измерений.
\end{enumerate}


Если результат оценки точности удовлетворяет заданным требованиям, то необходимо выполнить контрольные измерения. При создании сети СГС, необходимо выполнить контрольные измерения один раз с целью убедиться, что разности не превышают двойную точность.  При создании сети ВГС необходимо выполнить контрольные измерения не менее двух раз. При сопоставлении результатов необходимо убедиться, что разности не превышают допустимого значения.

\subsection{Уравнивание спутниковой сети в статике посредством метода нелинейного программирования}\label{subsec:ch3/sec1/sub3}

Наряду с классическими методами уравнивания спутниковых сетей используется методика уравнивания посредством применения методов нелинейного программирования \cite{src14,src16}. В спутниковых сетях в качестве измеренных величин принято рассматривать приращения координат между пунктами и на основании этого можно сформулировать ряд условий:

\paragraph{1. Условие фигур.}\label{Условие_Фигур}


Данное условие применимо в том случае, если в сети присутствует один исходный пункт. Его можно записать в виде системы \cref{eq:eq3.8}:

\begin{equation}\label{eq:eq3.8}
\!
\begin{cases}
\begin{aligned}
	&(dX_{12} &&+ &&uX_{12}) &&+ &&(dX_{23} &&+ &&uX_{23}) &&- &&(dX_{31} &&+ &&uX_{31}) &&= &&0 \\
	&(dY_{12} &&+ &&uY_{12}) &&+ &&(dY_{23} &&+ &&uY_{23}) &&- &&(dY_{31} &&+ &&uY_{31}) &&= &&0 \\
	&(dZ_{12} &&+ &&uZ_{12}) &&+ &&(dZ_{23} &&+ &&uZ_{23}) &&- &&(dZ_{31} &&+ &&uZ_{31}) &&= &&0 \\
\end{aligned}
\end{cases},
\end{equation}
где: 
\begin{description}
	\item[$dX_{ij},$ $dY_{ij},$ $dZ_{ij}$] ---~ приращения координат; 
	\item[$uX_{ij},$ $uY_{ij},$ $uZ_{ij}$] ---~ поправки к приращениям координат.
\end{description}

Аналогично происходит описание остальных фигур, входящих в состав сети: треугольники, четырехугольники, $\ldots (n-1)$-угольники –-- для сети, состоящей из $n$ пунктов.



\paragraph{2. Условие ходов.}\label{Условие_Ходов}


Данное условие возникает, если в исходной спутниковой сети более одного исходного пункта. 
Условие приведено в виде системы формул \cref{eq:eq3.9}:


\begin{equation}\label{eq:eq3.9}
	\!
	\begin{cases}
		\begin{aligned}
			&(dX_{12} &&+ &&uX_{12}) &&+ &&X_{1} &&- &&X_{2}  &&= &&0 \\
			&(dY_{12} &&+ &&uY_{12}) &&+ &&Y_{1} &&- &&Y_{2}  &&= &&0 \\
			&(dZ_{12} &&+ &&uZ_{12}) &&+ &&Z_{1} &&- &&Z_{2}  &&= &&0 \\
		\end{aligned}
	\end{cases},
\end{equation}
где: 
\begin{description}
	\item[$dX_{ij},$ $dY_{ij},$ $dZ_{ij}$] ---~ приращения координат; 
	\item[$X_{i},$ $Y_{i},$ $Z_{i}$] ---~ эталонные координаты пунктов.
\end{description}



\paragraph{3. Условие координат (параметрический метод).}\label{Условие_Координат}


Данное условие применимо в том случае, если в сети присутствует один исходный пункт. 
Условие можно записать в виде системы~\cref{eq:eq3.10}:


\begin{equation}\label{eq:eq3.10}
	\!
	\begin{cases}
		\begin{aligned}
			&(dX_{ij} &&+ &&uX_{ij}) &&+ &&(dX_{j} &&+ &&uX_{j}) &&- &&(dX_{i} &&+ &&uX_{i}) &&= &&0 \\
			&(dY_{ij} &&+ &&uY_{ij}) &&+ &&(dY_{j} &&+ &&uY_{j}) &&- &&(dY_{i} &&+ &&uY_{i}) &&= &&0 \\
			&(dZ_{ij} &&+ &&uZ_{ij}) &&+ &&(dZ_{j} &&+ &&uZ_{j}) &&- &&(dZ_{i} &&+ &&uZ_{i}) &&= &&0 \\
		\end{aligned}
	\end{cases},
\end{equation}
где: 
\begin{description}
	\item[$dX_{ij},$ $dY_{ij},$ $dZ_{ij}$] ---~ приращения координат; 
	\item[$uX_{ij},$ $uY_{ij},$ $uZ_{ij}$] ---~ поправки к приращениям координат;
	\item[$X_{k},$ $Y_{k},$ $Z_{k}$] ---~ приближенные координаты пунктов;
	\item[$uX_{k},$ $uY_{k},$ $uZ_{k}$] ---~ поправки к координатам.
\end{description}



Таким образом происходит описание всех векторов, входящих в структуру сети.

В дальнейшем вводится целевая функция (далее «ЦФ»). 
\nomenclature{ЦФ}{целевая функция \nomrefpage}
В случае спутниковых сетей ЦФ является сумма квадратов поправок к приращениям координат и к пунктам сети. Математически можно записать в виде формулы \cref{eq:eq3.11}.


\begin{equation}\label{eq:eq3.11}
	\text{ЦФ}=\sum(u_{dX}\cdot u_{dY}\cdot u_{dZ})^2 ,
\end{equation}


Как и в любой оптимизационной задаче, вводятся ограничения. В случае параметрической записи исходных данных сети можно сформулировать 2 ограничения:
\begin{enumerate}
	\item Невязки в векторе должны равняться нулю. 
	\item Поправки к координатам исходного пункта также равны нулю.
\end{enumerate}

Первое ограничение представлено в формуле~\cref{eq:eq3.10} применяемой для параметрической формы записи оптимизационной задачи.

Второе ограничение можно представить в виде формулы~\cref{eq:eq3.12}:


\begin{equation}\label{eq:eq3.12}
	\!
	\begin{cases}
		\begin{aligned}
			&v_{X_\text{исх.}} &&= &&0 \\
			&v_{Y_\text{исх.}} &&= &&0 \\
			&v_{Z_\text{исх.}} &&= &&0 \\
		\end{aligned}
	\end{cases},
\end{equation}

\section{Методика построения геодезических сетей при использовании РРР-алгоритма}\label{subsec:ch3/sec2}


В рамках кандидатской диссертации разработана методика построения Государственных Геодезических Сетей (далее «ГГС»)
\nomenclature{ГГС}{Государственныхе Геодезические Сети \nomrefpage}
 при использовании РРР-алгоритма. Ниже приводится разработанная методика.

%\paragraph{1. Общие положения} \phantom{CRLF}
\subsection{Общие положения}

\begin{enumerate}
	\item В настоящей методике описывается новый подход к построению ГГС, а именно при использовании методов высокоточных координатных определений (Precise Point Positioning)
	\item Проектирование работ выполняют в соответствии с действующими локальными, региональными, федеральными, государственными нормативными актами. На сегодняшний день действуют(ГКИНП01-271- 03[]; ГОСТ Р 57372-2016[]; ГКИНП (ОНТА)-02-262-02[]; ГОСТ 33472- 2015[]; ГОСТ 57373-2016[]).
\end{enumerate}

\subsection{Создание геодезических сетей при использовании РРР-алгоритма}

На сегодняшний день можно выделить ряд основных этапов создания геодезических сетей \cite{mak09,src33}.

\begin{enumerate}
	\item	Предпроектное обследование пунктов и контрольные измерения.
	\item	Проектирование.
	\item	Рекогносцировка, обследование и закладка пунктов сети.
	\item	Полевые наблюдения и предварительная обработка результатов на исходном пункте.
	\item	Камеральная обработка на исходном пункте.
	\item	Полевые работы и предварительная обработка на пунктах каркасной сети.
	\item	Камеральная обработка на каркасных пунктах.
	\item	Передача данных для включения в состав ГГС.
	\item	Полевые	и	предварительные	работы	на	пунктах	спутниковой геодезической сети.
	\item	Камеральная обработка спутниковых измерений на пунктах СГС (спутниковой геодезической сети).
\end{enumerate}

\subsection{Текущие точностные характеристики, предъявляемые к построению ГГС}

\subsubsection{В случае пунктов ВГС}

\begin{enumerate}
	\item	Положение пунктов определяется с СКП относительно пунктов ФАГС и других пунктов ВГС с погрешностью в плане не более $3$ мм $+5\cdot10^{-8}\cdot D$; по высоте не более $5+7\cdot 10^{-8}\cdot D$.
	\item	Пункты должны быть расположены в диапазоне расстояний от $150$ до $200$~км.
	\item	Относительная погрешность определения линий не грубее $1:1000000$ 
	
	Относительная погрешность в статике
\end{enumerate}


\subsubsection{В случае пунктов ВГС}

\begin{enumerate}
	\item	Положение пунктов определяется с СКП относительно пунктов ВГС с погрешностью в плане не более $3$ мм $+5\cdot10^{-7}\cdot D$; по высоте не более $5+2\cdot 10^{-7}\cdot D$.
	\item	Пункты должны быть расположены в диапазоне расстояний от $25$ до $35$~км.
	\item	Относительная погрешность определения линий не грубее $1:1000000$.
	\item	Относительные погрешности определения линий не зависят от расстояний при использовании РРР-методов. Подробнее было рассмотрено в главе \cref{ch:ch2} диссертационной работы, а также в статьях [ссылки на статьи $\ldots$].
\end{enumerate}

\subsection{Предлагаемая методика построения геодезических сетей с использованием РРР-алгоритма}

\subsubsection{Основные этапы выполнения полевых и камеральных работ}

\begin{enumerate}
	\item Выполнение полевых работ: 
	\begin{itemize}
		\item Измерения происходят в статическом режиме на протяжении трёх часов.
		\item При проведении полевых работ используется многочастотные и мультисистемные спутниковые приемники.
	\end{itemize}
	\item Спутниковые сети могут быть как свободными, так и несвободными.
	\begin{itemize}
		\item При построении свободной сети в её состав должен быть включен один твердый (исходный) пункт.
		\item Для построении несвободной сети в её состав требуется не менее двух опорных пунктов.
	\end{itemize}
	\item Измерения должны быть независимыми. В случае спутниковых методов построения геодезических сетей, независимость измерений достигается их проведением в разные сеансы.
	\item Контрольные измерения на пунктах геодезической сети выполняются не ранее, чем через 12 часов.
	\item Выполнение камеральных работ:
	\begin{itemize}
		\item Получение данных высокоточных эфемерид (ВЭ)
			\footnote{
				ВЭ могут быть получены как с сайтов международных сетей: ITRF, SOPAC; или, например, на сайте сети базовых станций EFT COORS. 
				
				На сегодняшний день продолжительность ожидания ВЭ составляет от 12 до 18 дней.
			}.
		\item Обработка сырых данных измерений
			\footnote{
				Обработка происходит с использованием интернет-сервисов: Trimble RTX, CRSR, IGN; либо с применением программных обеспечений: Bernese, Grafnet, GIPSY OASIS, Trimble Business Centre (TBC), КРЕДО ГНСС.
			}.
		
	\end{itemize}
	\item Уравнительные вычисления:
	\begin{itemize}
		\item Обработка данных и уравнивание сети возможны как с использованием интернет-сервисов, так и с применением программных обеспечений.
		\item Обработка и уравнивание с использованием программных обеспечений происходит в соответствии с заложенной методикой.
		\item При обработке данных по РРР-алгоритму при использовании интернет-сервисов уравнивание проиcходит стандартным образом в соответствии с МНК, \nomenclature{МНК}{Метод наимньших квадратов \nomrefpage} что приводится в виде формулы \cref{eq:eq3.6}.\newline Более подробно про классический способ уравнивания рассказано в разделе~\cref{УКС}.
		\item При использовании методов нелинейного программирования существует 2 подхода, применяемых в случае свободной сети:

				
			\paragraph*{Условный способ.}
			
			Для построения свободной спутниковой сети необходимы независимые измерения, т.е. измерения на пунктах сети выполняются в несколько сеансов.
			
			Условие описывается системой~\cref{eq:eq3.8}.
			
			Более подробно способ описан в разделе~\cref{Условие_Фигур}.
			
			\paragraph*{Параметрический способ.}
			
			Условия приведены в системе~\cref{eq:eq3.10}.
			
			Более подробно способ описан в разделе~\cref{Условие_Координат}.
			


		\item При построении несвободной спутниковой сети возможна только параметрическая форма записи. Условие приведено в виде системы формул~\cref{eq:eq3.35}.

	

			\begin{equation}\label{eq:eq3.35}
				\!
				\begin{cases}
					\begin{aligned}
						&(dX_{ij} &&+ &&uX_{ij}) &&+ &&X_{j} &&- &&X_{i} &&= &&0 \\
						&(dY_{ij} &&+ &&uY_{ij}) &&+ &&Y_{j} &&- &&Z_{i} &&= &&0 \\
						&(dZ_{ij} &&+ &&uZ_{ij}) &&+ &&Z_{j} &&- &&Z_{i} &&= &&0 \\
					\end{aligned}
				\end{cases},
			\end{equation}
			где: 
			\begin{description}
				\item[$dX_{ij},$ $dY_{ij},$ $dZ_{ij}$] ---~ приращения координат; 
				\item[$uX_{ij},$ $uY_{ij},$ $uZ_{ij}$] ---~ поправки к приращениям координат;
				\item[$X_{k},$ $Y_{k},$ $Z_{k}$] ---~ приближенные координаты пунктов.
			\end{description}

	\end{itemize}


	\item Контроль и оценка точности.

		Для контроля точности необходимы повторные измерения. 
	\begin{itemize}		
		\item Для сетей повышенной точности потребуется не менее трёх сеансов измерений. 
		\item Для сетей, менее требовательных к точности достаточно выполнить один повторный сеанс.
	\end{itemize}
	
		Можно выделить два подхода к оценке точности:
	\begin{itemize}
			\item Метод невязок ---~ происходит поиск невязок по замкнутым фигурам, например, треугольникам.
			\item Оценка точности геодезической сети происходит по алгоритму оценки разностей двойных измерений.
	\end{itemize}
	
		Для оценки точности может быть применена формула~\cref{eq:eq3.36}.
			\begin{equation}\label{eq:eq3.36}
				m_{d}=\sqrt{\dfrac{\sum{d^{2}}}{n}}
			\end{equation}
			где: 
			\begin{description}
				\item[$d$] ---~ разности двойных измерений; 
				\item[$n$] ---~ количество пар двойных измерений.
			\end{description}

		При этом средняя СКО\nomenclature{СКО}{Среднеквадрати́ческое отклонение \nomrefpage} может быть выражена в виде формулы~\cref{eq:eq3.37}.
			\begin{equation}\label{eq:eq3.37}
				m_{x_{\text{ср}}}=\dfrac{m_{X}}{\sqrt{2}}=\dfrac{1}{2}\cdot \sqrt{\dfrac{\sum{d^{2}}}{n}}
			\end{equation}

\end{enumerate}


Методику построения геодезических сетей при использовании РРР-алгоритма обработки спутниковых данных условно можно разбить на три основных этапа:

	\item уравнивание сети и финальная оценка точности (рисунок~\cref{fig:pic36}).
\end{enumerate}

\subsection{Заключение по главе}\label{subsec:ch3/sec3/sub6}

 В первой части главы рассмотрены основные этапы создания геодезических сетей классическим методом на примере статики. Приводится эксперимент по уравниванию сети в статике. Далее рассматривается фрагмент современной методики создания сетей по \textit{классической постобработке}.
 
 Во второй части главы предложена методика построения геодезических сетей в три основные этапа.
 
 Предложенная методика создания сети показывает свою актуальность по следующим пунктам:
 \begin{enumerate}
 	\item Уменьшение временных затрат на выполнение полевых работ.
 	\item Отсутствие влияния расстояний на точность передачи координат.
 	\item Повышение точности определения координат, по сравнению с классической обработкой в статике.
 \end{enumerate}
 
 Далее в главе рассмотрены эксперименты по исследованию точности построения геодезических сетей с использованием РРР-алгоритма обработки спутниковых данных.
